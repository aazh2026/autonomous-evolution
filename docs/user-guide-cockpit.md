# ASES 控制舱（Cockpit）用户操作手册

> 面向人类指挥官、架构师与系统运维人员的交互式界面操作指南。
> 对应的架构设计见 [`docs/architecture/frontend-design.md`](frontend-design.md)，控制面 API 见 [`apps/api/control.py`](../../apps/api/control.py)。

---

## 1. 快速接入与控制台概览

ASES 控制舱（Cockpit & Court）采用现代化、无外部构建依赖的交互式单页架构，随系统 API 服务一体化提供。

### 1.1 访问地址
- **控制舱前端 UI**：`http://localhost:8008/ui`（或根路径 `http://localhost:8008/`）
- **OpenAPI 调试终端**：`http://localhost:8008/docs`
- **系统健康探针**：`http://localhost:8008/healthz`

### 1.2 界面主区域分布
控制舱全屏划分为四大功能交互区：
1. **顶部安全控制中枢（Top Bar）**：全局态势、自主权等级切换、日预算仪表盘、暂停与物理急停熔断。
2. **左侧周期与导航栏（Left Sidebar）**：历史演进周期列表、五大核心视图切换、执行器集群舰队状态。
3. **中央主工作舞台（Main Stage）**：双环态势看板、决策沙盘、DAG 任务流、六层验证矩阵、高风险审批法庭。
4. **底部实时遥测流（Telemetry Drawer）**：底层 Coding Agent 思考、执行、验证的实时 NDJSON 事件日志。

## 2. 顶部安全与自主权控制操作

顶部栏是人类指挥官接管与调控系统运行状态的核心中枢。

### 2.1 自主权等级切换（Autonomy Levels）
点击顶部中央切换开关，系统支持四级自主权实时无缝热切换：
- **L0 纯手动模式（Manual）**：系统仅生成改进建议，不自动立项、不启动执行器。
- **L1 监督模式（Supervised）**：系统自动拆解规划路线图，但任务派发与代码合并必须经人工点击确认。
- **L2 半自主模式（Semi-Autonomous · 默认）**：常规任务（Bug 修复、测试补齐、常规重构）自主闭环；高风险变更（架构改动、契约变更）自动拦截并推送至审批法庭。
- **L3 全自主巡航（Full Autonomous）**：在预设日预算与安全约束范围内，系统全自主全天候运行。

### 2.2 预算仪表盘监控
- 实时显示当日已消耗金额与每日硬顶上限（如 `$1.26 / $5.00`）。
- 达到或超出预算上限时，系统自动切断新任务派发，防止费用超支。

### 2.3 暂停与急停熔断（Emergency Kill Switch）
- **暂停闭环（Pause/Resume）**：
  - 点击「暂停闭环」，当前正在执行中的任务会安全完成，但暂缓派发新任务。
  - 按钮切换为绿色「恢复演进」，再次点击即可继续调度。
- **急停熔断（Emergency Stop）**：
  - 点击红色「急停熔断」按钮，系统弹出防误触二次确认窗。
  - 确认后立即强制终止所有底层子进程，冻结 Git Worktree 租约，并持久化当前系统断点。

## 3. 五大核心功能视图操作指南

点击左侧导航栏可即时在五大工作视图间切换：

### 3.1 视图 1：双环态势与目标达成（Dual-Loop Dashboard）
*快捷导航：点击「双环态势与目标达成」*
- **指标卡片解读**：
  - **目标达成度（Attainment）**：反映项目核心演进目标的达成比例（如 `0.5554 (▲ +0.1962)`）。
  - **已知缺陷收敛**：跟踪针对性修复缺陷的收敛进度。
  - **代码行与分支覆盖率**：基于实际运行测试矩阵计算的最新覆盖率增益。
  - **单位增益成本效率**：完成当前演进周期所消耗的实际模型与计算费用。
- **双环流转状态图**：直观展示宏观发现环（Loop B）与微观受控执行环（Loop A）的当前所处阶段。

---

### 3.2 视图 2：演进决策沙盘（Decision Sandbox）
*快捷导航：点击「演进决策沙盘」*
展示系统自主观察项目后挖掘出的演进机会（Candidates）与裁决结果：
- **置信度红绿灯**：
  - **绿色徽标（≥ 0.80，确凿/高置信）**：具备真实失败用例或代码行确凿证据，系统建议立项（Record）。
  - **红色徽标（< 0.50，投机/低置信）**：纯猜测性或性价比不足的修改，系统自动推迟（Defer），严格践行「不行动也是合法决策」。
- **指挥官人工覆盖（Human Override）**：
  - 每张候选卡片下方提供「强制立项」与「推迟」快捷操作。
  - 点击后弹出原因录入框，填入覆盖理由即可实时变更决策状态，并将操作人签名与理由存入审计数据库。

---

### 3.3 视图 3：DAG 多任务调度流（Task DAG Topology）
*快捷导航：点击「DAG 多任务调度流」*
- **按执行波次（Waves）呈现**：
  - **Wave 0**：无依赖的基础任务（如先行修改核心模块）。
  - **Wave 1**：依赖 Wave 0 产出的下游任务（如追加回归测试用例、配置同步）。
  - **Wave 2**：终态集成与文档同步任务。
- **节点状态色彩规范**：
  - 绿色徽标：`COMPLETED`（已成功合并）
  - 蓝色呼吸动画：`RUNNING`（执行器正在处理）
  - 灰色徽标：`READY`（等待并发槽位调度）
  - 红色警示：`BLOCKED`（因上游任务失败而自动级联阻断，防止雪崩扩散）

---

### 3.4 视图 4：六层验证与代码差异（Verification & Diff）
*快捷导航：点击「六层验证与代码差异」*
- **左栏 · 隔离工作区代码 Diff**：
  - 显示当前任务在独立 Git Worktree 隔离区内的具体代码变更行。
  - 绿色标识新增代码，红色标识删除代码。
- **右栏 · 独立六层验证矩阵（Six-Layer Matrix）**：
  - 严格由独立外部进程执行验证，严禁使用 Agent 的自我汇报结果。
  - 包含六大独立判定项：
    1. **① 功能验收（Functional）**：Pytest 单元与集成测试（区分 xfail / xpass）。
    2. **② 代码质量（Code Quality）**：Ruff Lint 零警告与 Mypy Strict 静态类型安全。
    3. **③ 架构守约（Architecture）**：AST 依赖调用无跨层违规。
    4. **④ 安全扫描（Security）**：Bandit 漏洞扫描与高危权限审计。
    5. **⑤ 性能基准（Performance）**：执行时间是否劣于历史性能基线。
    6. **⑥ 产品契约（Product Spec）**：前置契约条件验收达成。

---

### 3.5 视图 5：高风险审批法庭（Governance Court）
*快捷导航：点击「高风险审批法庭」*
左侧导航带有红色待办角标（如当前有 `1` 笔待审批）。
- **审批卡片要素**：
  - **目标任务与改动摘要**：改动的关键路径与行数变化。
  - **风险等级（Risk Level）**：如 `HIGH RISK`（涉及核心架构或治理策略改动）。
  - **防篡改内容指纹（Content Digest）**：SHA-256 哈希值，确保放行的代码内容未被恶意篡改。
  - **评审资格（Required Scopes）**：标注放行所需的主审资格（如 `architecture`, `governance`）。
- **审批动作**：
  - **签名放行（Approve）**：签署架构师资格标记，解锁代码合并门禁。
  - **驳回合并（Reject）**：拒绝入仓，将原因反哺给决策系统进行后续再规划。

## 4. 底部实时遥测与执行器舰队

### 4.1 实时遥测流（Telemetry Stream）
- 界面底部暗色终端抽屉每隔 3 秒自动轮询后端最新 NDJSON 遥测事件流。
- 事件类型标签：
  - `session.start`：执行器分配与工作区隔离租约生成。
  - `thought`：模型上下文思考过程。
  - `action`：文件读写与命令行工具调用。
  - `verify`：真实触发外部测试命令的中间反馈。
  - `result`：任务终态确认与分支产物归档。

### 4.2 左下角执行器集群舰队（Fleet Status）
- 实时展示当前在线适配器（Claude Code、Codex、Gemini CLI、OpenCode）的健康状态、并发配额与历史成功率。
- 标明动态执行器调度器（Task-to-Executor Affinity）的分配亲和度。

## 5. 常见运维与排查操作

| 场景 | 推荐操作 |
| :--- | :--- |
| **需要临时人工介入修改代码** | 将自主权切至 **L0** 或 **L1**，并在终端直接进入对应 Worktree 目录处理。 |
| **观察到测试耗时异常或模型死循环** | 点击右上角「**急停熔断**」冻结进程，检查遥测流中的异常工具调用。 |
| **修改了前端静态资源需生效** | 页面支持原生无缓存刷新（`Cmd + Shift + R` 或 `F5`），后端内嵌模板会自动热加载。 |
| **更换监听端口** | 执行启动命令时附加 `--port <PORT>` 参数，如 `./scripts/start_cockpit.sh --port 8080`。 |
