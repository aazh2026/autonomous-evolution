# 自适应调度回放 —— 调度 vs 静态分配

- 决策位：**3** 个（一次任务的一次尝试算一个位）
- 历史口径：账本里装的是**这一位之前所有格子跑过的**（像一张在长的能力矩阵）
- 调度规矩：容差 0.05、底线 0.0、冷启动偏好 claude-code/MiniMax-M3、每 0 次探一次
- 结果口径：**做对了就用那一格在同一位的真实记录来算** —— 每一个数都是实测出来的，只有'挑哪个'是反事实的。
- 成功率 = 跑成了几次里做对几次；**没跑成的不进分母**。

- **adaptive**：按历史调度：先保达成度，底线之内按成本排
- **declared-default**：始终用事先声明的默认组合 —— 静态分配的原样
- **cheapest-a-priori**：按公开价目表挑最便宜的模型 —— 事先就知道的静态分配
- **round-robin**：所有格子轮着来 —— 静态分配里最讲道理的一种

## 同样的钱能做对几件事

每格是 **预算内做对 / 预算内**（没量到成本的那一位不进预算内）。
